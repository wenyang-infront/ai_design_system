# Colors

Color is organized into primitive palettes and semantic roles. Components consume semantic roles such as `text.primary`, `background.canvas`, and `border.default`; primitives are reserved for token definitions and visual exploration.

## Guidance

Use color to establish hierarchy, signal status, and support interaction. Check foreground and background combinations in every theme and do not use hue as the only state cue.
