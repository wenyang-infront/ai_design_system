# Enterprise Design System

This is the living reference for product teams building consistent, accessible interfaces. Use Foundations for visual decisions, Components for implementation guidance, and the Accessibility page before shipping.

## How to use this library

1. Start with a foundation token instead of a raw value.
2. Choose the component variant that matches the user intent.
3. Validate keyboard, focus, and error behavior in the component story.

## Contribution standard

Every new component should include an overview, variants, states, accessibility guidance, and token dependencies. Stories are the contract between design, engineering, and QA.
