# Design Principles

## Clear before clever

Use familiar patterns, direct labels, and a predictable hierarchy. Visual expression should support recognition and decision-making.

## Designed for change

Prefer composable components and semantic tokens. A product theme or density mode should be able to change without rewriting component intent.

## Inclusive by default

Keyboard operation, readable contrast, visible focus, and meaningful names are core behavior, not polish added at the end.

## Calm density

Use spacing and elevation to group related work. Reserve emphasis for actions and information that genuinely need attention.
