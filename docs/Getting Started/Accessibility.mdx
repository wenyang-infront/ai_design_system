# Accessibility

Build to WCAG 2.2 AA as the baseline. Every interactive story should be usable with a keyboard, expose an accessible name, preserve a visible focus indicator, and communicate state changes to assistive technology.

## Review checklist

- Use native elements where they provide the right semantics.
- Associate labels, help text, and errors with their control.
- Never rely on color alone to communicate state.
- Keep focus visible and the reading order logical.
- Run the Storybook Accessibility panel against every state.
