# Modal

Modals interrupt the current task for a focused decision or short workflow. Use them only when the user must respond before continuing.

## Accessibility

The dialog exposes a name, modal state, keyboard-operable close action, and a visible focus entry point. Production use should trap focus and restore it to the invoking control on close.

## Token dependencies

`background.canvas`, `text.primary`, `elevation.level.3`, `radius.large`, and `spacing.300`.
