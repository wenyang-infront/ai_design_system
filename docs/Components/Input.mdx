# Input

Inputs collect a single value. Labels remain visible, help text sets expectations, and errors explain how to recover.

## Accessibility

The label is programmatically associated with the input. Hint and error content are referenced with `aria-describedby`, and invalid values expose `aria-invalid`.

## Token dependencies

`color.text.primary`, `color.border.default`, `color.feedback.error`, `radius.medium`, and `spacing.100`.
