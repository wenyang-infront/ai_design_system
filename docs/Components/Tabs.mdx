# Tabs

Tabs organize peer views without changing the page context. Keep labels short, stable, and parallel in grammar.

## Accessibility

The component uses `tablist`, `tab`, and `tabpanel` roles with explicit relationships and a visible selected state. A production implementation should also support arrow-key navigation.

## Token dependencies

`color.text.primary`, `color.border.default`, `color.brand.primary`, and `spacing.150`.
