# Button

Buttons trigger an action. Use a concise verb, choose one primary action per context, and use destructive intent only when the consequence is clear.

## Button Anatomy

The anatomy below shows the parts that make up a medium, filled button. Icons are optional and should reinforce the action rather than repeat the label.

1. **Container** - The button surface uses the variant background and border tokens, a `1px` border, `spacing.200` horizontal padding, and `radius.medium` (`8px`) corner radius. The container must remain large enough to provide a usable pointer target.
2. **Label** - The visible action uses the `labelMedium` typography token (`600`, `14px`) and the appropriate content color, such as `color.text.onBrand` on a filled primary button. Use concise, action-oriented text.
3. **Leading Icon (optional)** - Place an icon before the label when it clarifies the action. Keep it decorative with `aria-hidden="true"` when the label already communicates the action, and preserve the component's `spacing.100` (`8px`) gap.
4. **Trailing Icon (optional)** - Place an icon after the label for actions such as opening a menu or navigating. The icon must not be the only accessible name unless the control is explicitly icon-only.
5. **Focus Ring** - `:focus-visible` adds a `3px` `color.brand.primary.hover` outline with a `2px` offset. Keep it visible for keyboard users and do not rely on color alone to communicate focus.
6. **Loading Indicator (when applicable)** - The spinner uses `currentColor`, is hidden from assistive technology, and is paired with `aria-busy="true"`. The button is disabled while loading, but its label remains visible so the action stays understandable.
7. **Disabled State** - A disabled button uses the native `disabled` attribute, reduced opacity, and a not-allowed cursor. Do not use disabled state to hide validation or other essential feedback.

## Variants

The stories cover filled, outlined, text, disabled, loading, and focus-visible behavior. Loading preserves the action label while exposing busy state.

## Sizes

Small, medium, and large sizes change the control height, horizontal padding, and label scale while preserving the same anatomy and interaction states.

## States

Button states include default, hover, pressed, focus-visible, loading, and disabled. Each state preserves the button's accessible name and communicates its status without relying on color alone.

## Accessibility

Use a native button, provide an accessible label when the visible label is insufficient, and never disable a button to hide an error message.

## Design Tokens

`color.brand.primary`, `color.text.onBrand`, `color.border.default`, `radius.medium`, and `spacing.200`.
