# Select

Select is for choosing one option from a known, manageable list. Prefer a different pattern when users need search, multiple selection, or freeform entry.

## Accessibility

The native select preserves keyboard behavior and platform conventions. Keep the visible label and option names specific.

## Token dependencies

`color.text.primary`, `color.border.default`, `radius.medium`, and `spacing.100`.
